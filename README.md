# UI 动效实验室

用可运行的小样记录界面动效的设计判断与实现参数。第一个实验是**卡片扫光与双尺寸闪光**。

[打开演示文件](./index.html)

## 01 · 卡片扫光

卡片底色用渐变制造层次，半透明光带从左到右掠过。两颗星芒错开出现。页面使用原创示例文案与图形，不包含业务素材。

| 项目 | 当前参数 | 调整方向 |
| --- | --- | --- |
| 循环周期 | 5.2 秒 | 缩短更活跃，延长更克制 |
| 光带移动 | 周期的 10%–42% | 调整光到达卡片的时机 |
| 主闪光 | 周期的 20%–27% | 贴近视觉焦点 |
| 次闪光 | 延后 0.3 秒 | 形成先后节奏 |
| 缓动 | ease-in-out | 让起止更柔和 |

## 查看与修改

下载 `index.html`，直接在浏览器打开，无需安装依赖。搜索 `sweep`、`twinkle` 可以调整节奏。点击“暂停动效”可停下效果；开启系统“减少动态效果”时，页面会关闭动画。

## 设计记录

- 光带用宽而低透明度的边缘过渡，减少硬切感。
- 星芒使用 SVG 路径，大小可缩放，中心保持清晰。
- 动效用于强调卡片质感，文案与操作不依赖动画理解。

这是一个独立的动效研究项目，不代表任何公司产品或品牌。
