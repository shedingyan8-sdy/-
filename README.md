## 01 · 卡片扫光

卡片底色用渐变制造层次，半透明光带从左到右掠过。两颗星芒错开出现。

| 项目 | 当前参数 | 调整方向 |
| --- | --- | --- |
| 循环周期 | 5.2 秒 | 缩短更活跃，延长更克制 |
| 光带移动 | 周期的 10%–42% | 调整光到达卡片的时机 |
| 主闪光 | 周期的 20%–27% | 贴近视觉焦点 |
| 次闪光 | 延后 0.3 秒 | 形成先后节奏 |
| 缓动 | ease-in-out | 让起止更柔和 |

光带采用宽而低透明度的边缘过渡。星芒使用 SVG 路径，大小可缩放。动效只强调材质感，文案与操作不依赖动画理解。
